# 💕 Romantic Proposal Site 💕

Um site lindo e romântico com fogos de artifício para pedir casamento!

## 🎆 Características

- ✨ Fogos de artifício animados em tempo real
- 💬 Mensagem romântica: "Eu Te Amo Meu Amor Para Sempre"
- 💍 Pergunta de casamento interativa
- 🎨 Design moderno com gradientes bonitos
- 📱 Responsivo para dispositivos móveis
- 🖱️ Clique em qualquer lugar para mais fogos!

## 🚀 Como Acessar

O site está hospedado automaticamente no GitHub Pages!

**Link:** https://felipecigerza4-wq.github.io/romantic-proposal-site/

Basta acessar o link acima no seu navegador e aproveitar o site!

## 🎮 Como Usar

1. Abra o site no link acima
2. Veja os fogos de artifício animados automaticamente
3. Clique no botão "SIM!" para celebrar
4. Clique em qualquer lugar da tela para mais fogos de artifício
5. O botão "Não" se move quando você tenta clicar 😉

## 📁 Arquivos

- `index.html` - Página principal
- `style.css` - Estilos e animações
- `fireworks.js` - Lógica dos fogos de artifício
- `script.js` - Interatividade

## ❤️ Personalizações

Você pode editar o arquivo `index.html` para:
- Mudar a mensagem
- Alterar as cores
- Adicionar mais texto
